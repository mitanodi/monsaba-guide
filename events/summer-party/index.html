アルバムの基本ルール

  1. カードはカードパックから入手します。カードパックはランニングパーティ、オタカラ探しなどのゲーム内イベントで入手できます。
  2. 1セット9枚をそろえるとセット完成報酬を獲得できます。今期アルバム内の全セット完成で目玉報酬を獲得できます。
  3. 今回のイベントで獲得できるアイコンフレームは永久アイテムです。
  4. パック開封で重複カードを獲得すると、そのカードの星ランクと同じ数のスターを追加で獲得します。スターは報酬と交換できます。

カード交換・プレゼント

  1. 余ったカードは他のトレーナーと交換・プレゼントできます。
  2. 金カードの交換・プレゼントは特定の時期に限られます。今回の証拠だけでは現在が対象期間か断定しません。
  3. プレゼントは、そのカードを持っていないトレーナーにのみ行えます。
  4. 交換を申し込めるのは、自分が未所持のカードだけです。
  5. 1日のプレゼント・交換には回数制限があります。失敗・撤回時は消費回数が返還されます。
  6. プレゼントまたは交換が完了するとスター×1を獲得します。この方法で1日に得られるスター数には上限があります。

カードコレクションとは？

  1. カードローダーを使ってお気に入りカードを装飾できます。
  2. 装飾したカードは思い出ギャラリーへ展示できます。
  3. カードローダーが不足している場合は、1個につきビー玉100で購入できます。
  4. 今期アルバム終了後も、未使用のカードローダーは次期アルバムへ持ち越されます。
Card Loader → Memory Gallery

カードを選択 → カードローダーを使用 → 「飾る」 → 思い出ギャラリーへ展示、という流れです。
