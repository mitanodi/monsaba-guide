卡册基本规则

  1. 卡片来自卡包；卡包可从跑步派对、寻宝等游戏内活动获得。
  2. 集齐一套9张卡可获得整套奖励；完成本期卡册的全部套组可获得重点奖励。
  3. 本次活动中可获得的头像框为永久道具。
  4. 开包获得重复卡时，会额外得到与该卡星级相同数量的星星；星星可兑换奖励。

卡片交换与赠送

  1. 多余卡片可与其他训练师交换或赠送。
  2. 金卡只能在特定时期交换或赠送；现有证据不能判断当前是否处于该时期。
  3. 只能把卡片赠送给尚未持有该卡的训练师。
  4. 只能申请交换自己尚未持有的卡片。
  5. 每天的赠送与交换有次数限制；失败或撤回时会返还已消耗次数。
  6. 赠送或交换完成后可获得1颗星星；通过此方式每天获得的星星存在上限。

什么是卡片收藏？

  1. 可使用卡片装饰器装饰喜欢的卡片。
  2. 装饰后的卡片可展示到回忆画廊。
  3. 卡片装饰器不足时，可用100颗弹珠购买1个。
  4. 本期卡册结束后，未使用的卡片装饰器会结转到下一期卡册。
Card Loader → Memory Gallery

选择卡片 → 使用卡片装饰器 → 点击装饰 → 展示到回忆画廊。
