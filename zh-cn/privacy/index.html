关于隐私和访问分析

我们将解释用于改进站点的访问分析。

访问分析

本网站使用 Vercel Web Analytics、Vercel Speed Insights 和 Google Analytics 4 (GA4) 来了解页面使用情况和显示速度并改进网站。

这些特征是通过分发该站点的Vercel系统来测量的。除了页面显示之外，还可以聚合导航、内部链接、搜索结果、过滤器、Tatari 比较、策略咨询/问题板使用、外部链接以及广告和联属链接的点击。

在GA4中，本站定义的浏览量、流量来源、使用环境、操作事件等信息通过Google标签发送给Google。谷歌可能会使用cookies和类似的识别技术。

站点搜索项/公告板搜索项、问题/答案/回复文本、任意名称、朋友UID、Tatari 名称、未决问题、发帖ID和IP地址将不会被发送到该站点自己的分析事件。搜索仅使用不识别个人的聚合值，例如字符数和结果数，并从传递给 GA4 的页面 URL 和引荐网址中排除查询字符串。您的选择只会保存在您的浏览器中，不会发送到我们的服务器。

保存在设备中

您对策略咨询、朋友帖子和问题板帖子的删除、已解决操作的信息以及用于将来激活的A/B测试作业的选择都保存在您正在使用的浏览器的localStorage中。 A/B 测试当前已禁用，启用后不会保存您的姓名或联系信息等个人信息。

“我的Clash of Critters”的现有/演进阶段以及配置制造商保存的配置也仅保存在浏览器的本地存储中，并且不会发送到本站点的服务器。仅当用户创建共享 URL 时，该 URL 的接收者才能查看阵容数据。您拥有的 Tata 名称、Tata ID、发展阶段和阵容详细信息不会发送到此网站自己的 Analytics 活动。

好友招募

好友招募公告板保存发布的UID、任意用户名、级别、评论以及发布日期和时间。帖子将在 30 天后自动从列表中删除。

为了防止垃圾邮件，我们不存储发帖源IP地址本身，而是在必要的范围内使用不可逆的标识值。请不要发布除游戏内 UID 之外的任何个人信息。

Clash of Critters 问答板

问题公告板保存并发布发布的问题标题、文本、类别、任意名称、补充信息（例如使用的类型和级别）、答案、回复文本、任意名称以及发布日期和时间。请不要在问题/答案/回复中填写个人信息。

在反垃圾邮件措施中，不存储原始IP地址，并且在服务器侧使用秘密信息的不可逆标识值可以仅用于控制发布间隔。发帖者可以使用其设备上保存的删除信息删除他们的帖子，提问者可以将其标记为已解决。

每个帖子的举报都会被保存以供管理员审核，并且帖子不会仅仅通过举报而被自动删除。管理员将删除违反使用规则的问题、答案和回复。问题板上仅发送类别、操作类型、回复级别、项目数等匿名信息至 Analytics，不会发送标题、正文、答案、回复、姓名、搜索词、帖子 ID、回复 ID 和 IP 地址。

显示官方X帖子

在首页上，通过从我们网站的服务器查询X API来显示来自Clash of Critters官方X (@monsaba_jp)的公开帖子。 X API 身份验证信息永远不会发送到查看者的浏览器。

要显示发布的图像，请连接到X的图像分发域。选择发布链接之后对信息的处理将根据X的隐私策略。如果我们无法检索该帖子，我们只会向您显示官方 X 的常规链接。

A8.net和广告商可以使用cookie和类似的识别技术来达到诸如显示广告和测量性能之类的目的。在广告链接目的地输入的个人信息等的处理将按照链接的商业实体制定的隐私政策进行。

本网站本身并不直接获取通过A8.net申请者的姓名、地址、联系方式等个人信息。

关于引入Google AdSense的准备工作

该网站将来可能实施Google AdSense。目前，我们尚未安装 Google AdSense 广告分发代码，并且我们不使用此服务分发广告。

当被引入时，诸如谷歌之类的第三方分发者可以使用cookie和类似的识别技术来分发广告、测量有效性并防止未经授权的使用。您还可能会看到基于您的浏览历史记录等的个性化广告。

用户Google广告设置您可以管理您的个性化广告设置。实际实施 AdSense 时，请检查适用的同意要求和 Google 的最新政策，并再次更新此页面。
