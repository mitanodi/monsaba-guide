数据更新政策

可验证信息和现场评估将被分开处理。

显示标签

  • 官方确认 内容以游戏内公告或游戏内截图确认
  • 独立评估 本站根据已确认数据和公开策略信息作出的临时判断
  • 确认 因缺乏证据而有待结论或DB反映的内容

Tatari 名字/进化/技能

我们整理了用户提供的游戏内截图中确认的名称、进化阶段、技能描述和数字。

玩法攻略

本网站记录的公共策略信息和数据将被单独整理。参考信息将显示在保存源的策略页面上。

等级评价标准

按等级和模式的评估是本网站特有的基于已确认的技能、角色和目的的公共策略信息的临时评估。这不是官方排名。总体评级不会仅仅因为 Zombie Rush 的具体变化而自动更改。

进化优先级标准

我们将使用所需的星星数量、已确认的进化差异、策略目标和使用评价作为决定因素。如果材料短缺，将不确定优先顺序。

更新/验证日期管理

公开日期、更新日期、数据确认日期、目标环境和等待确认的项目被单独记录为页面管理数据。 Git 提交日期不被视为游戏内验证日期。

未知数据

无法确认的名称、效果、数字、策略条件将不会通过猜测进行修正。

评估待定

待评价并不意味着弱。目前，没有足够的证据对它们进行排名。

不正确信息的传达

如发现错误，请附上发表页及确认证明。操作员X联系。

官方创作者素材

部分图片使用了《Monster Survival》运营团队向创作者提供的游戏素材。这并不表示本站是官方攻略站、获得官方认证或属于官方合作伙伴。
