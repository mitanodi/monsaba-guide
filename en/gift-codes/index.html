How to redeem a gift code

  1. Open the Friends list
  2. Open Settings (the gear icon)
  3. Select “Gift Code”
  4. Enter the code exactly
  5. Tap OK
  6. Collect the reward in game

Gift codes may stop working without advance notice, so redeem them while they are still available.
