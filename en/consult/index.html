About the data

Create answers in the following ranges: data/tatari.json, data/tata-skills.json, data/tier-ratings.json, data/evolution-priority.json, data/content-guides.json. We will not make assumptions about content that is not included in the data, and will notify you as insufficient information.

Questions that cannot be answered using the site data can be answered by other users.Clash of Critters Q&A Board. The Guide Assistant beta answers from local site data, while the Q&A Board is for open questions and answers.
