Is ビリジカ strong?

Combining firepower and CC through penetration, paralysis, and binding. Overseas Overall/Boss/Dojo evaluations and domestic evaluations overlap, so it can be used for a long time in multiple modes.

Should you evolve ビリジカ?

  • T2→T3 priority candidate: Adds infinite penetration for every 4th attack. Penetration performance is greatly increased and is strengthened in situations where enemies are densely packed.

What changes when it evolves?

T1 ビリジカ → T2 デンジカ

  • Skill: ビリリランス → ボルトランス
  • Number of penetrations: 2 → 3

T2 デンジカ → T3 ジバジカ

  • Skill: ボルトランス → エレキランス
  • Infinite Penetration Frequency: Every 4th attack (additional)

T3 ジバジカ → T4 マグネクス

  • Skill: エレキランス → 超科学エレキランス
  • Aura/Lightning Attack speed increase initial value: 4% (additional)
  • Aura/Lightning Attack speed increase maximum: 20% (additional)
