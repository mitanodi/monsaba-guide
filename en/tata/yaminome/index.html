What changes when it evolves?

T1 Budboo → T2 Snapshade

  • Skill: 種ポイズン → 花ポイズン
  • Number of Mad Poison Seeds: 3 (Additional)

T2 Snapshade → T3 Thornwisp

  • Skill: 花ポイズン → 魔花ポイズン
  • Poison area Duration: 4 seconds (additional)

T3 Thornwisp → T4 Chomperwraith

  • Skill: 魔花ポイズン → 進化ポイズン
  • Aura/Grass HP increase initial value: 4% (additional)
  • Aura/Grass HP increase maximum value: 20% (additional)
