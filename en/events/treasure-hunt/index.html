      About this tool

      Probability is calculated by independently enumerating treasure placement candidates and excluding candidates that conflict with the input conditions. No code, HTML, or CSS from external sites is used. For large boards, it is an approximation that uses valid candidates up to the upper limit.

      Current event rules

      Externally confirmed Members can be reused, and each board opening increases the cost by 5. Use the independent solver above to compare the next candidate while accounting for four keys and bombs.
