      About this tool

      Small and medium cases count every valid layout. Large cases use deterministic branch-weighted sampling and board symmetries to reduce estimation bias. No code, HTML or CSS from external sites is used.

      How Treasure Hunt works

      Community-confirmed

      Keys and the central chest

      Choose four members when the event starts. Finding treasure three times on one member's board awards one key. Four keys open the central chest, and the same member can provide multiple keys.

      Cost, bombs and board expansion

      The required item cost rises by five for each key, and the board can expand up to three times. Bombs uncover one to three additional tiles. Use the original solver above to compare candidates.

      Human Verification

      Human Verification is still needed for the Japanese screens showing four-member selection, keys, the central chest, board expansion, bomb effects and the end time.
