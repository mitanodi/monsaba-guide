Event and feature names

Summer Party is the event. Album is the card-collecting feature. Card Collection is a separate feature for decorating favorite cards and displaying them in Memory Gallery.

Album

Card sets · Card packs · Exchange · Stars · Set rewards

Card Collection

Card Loader · Memory Gallery · Decorated cards

Album rules

  1. Cards come from card packs. Packs can be earned from in-game events such as Running Party and Treasure Hunt.
  2. Completing all nine cards in a set awards the set reward. Completing every set in the current Album awards the featured reward.
  3. The icon frame available from this event is a permanent item.
  4. A duplicate from a pack grants additional Stars equal to that card’s star rank. Stars can be exchanged for rewards.

Card exchange and presents

  1. Extra cards can be exchanged with or presented to other trainers.
  2. Gold-card exchanges and presents are limited to special periods. The supplied evidence does not establish whether one is active now.
  3. A card can be presented only to a trainer who does not own it.
  4. You can request only cards that you do not own.
  5. Daily exchange and present attempts are limited. A failed or withdrawn attempt refunds the consumed count.
  6. A completed exchange or present grants one Star. Stars earned this way have a daily cap.

What is Card Collection?

  1. Use a Card Loader to decorate a favorite card.
  2. Decorated cards can be displayed in Memory Gallery.
  3. If you need another Card Loader, one costs 100 marbles.
  4. Unused Card Loaders carry over to the next Album after the current Album ends.
Card Loader → Memory Gallery

Choose a card → use a Card Loader → select Decorate → display it in Memory Gallery.
