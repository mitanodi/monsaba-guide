    How to use the organization maker

    1. Select an empty slot from the 15 slots, specify the evolution stage, and place Tatari.
    2. If you select a mode such as Normal, Zombie Rush, or Dojo, you can check the existing tier distribution and role composition.
    3. You can save it on your device or create a shared URL, image, and text in hash format.
    4. If you are unsure, you can check and edit the content before posting to the question board. It will not be automatically posted.

    The shared URL includes only the family ID, evolution stage, placement, and mode. The content of the organization will not be sent to this site's server or Analytics.
