モンサバ シールド持ち・役割別タタ一覧

モンサバのシールド役2系統を、確認済み役割・用途別Tier・進化情報から比較します。通常、Zombie Rush、道場、初心者の使い分けも掲載。

確認済みDB当サイト独自整理

シールド役とは

当サイトのTier DBで「シールド」を役割に含む系統をまとめています。付与対象・量・条件などは、確認済みの個別スキル記載だけを根拠にします。

候補に入れやすい場面

回復とは別の生存補助を含む候補を探し、タンク・バフなど併用役割との違いを比較したいときに使えます。

優先度を下げる判断

シールドの数値や重複ルールを確認できていない場面では効果を断定しません。時間切れが課題なら、耐久だけでなく火力役も比較します。

用途別の使い分け

通常ステージ

通常Tierで上位の候補：トコペン系（SS）、フクロクモ系（S）。時間切れ・全滅など失敗理由に合わせ、通常ステージ攻略と個別スキルを確認します。

Zombie Rush

既存のZombie Rush Tierで上位の候補：トコペン系（SS）、フクロクモ系（A）。この列はSeason 1専用35系統データと混ぜず、最新状況はZombie Rush攻略で確認します。

バッジ道場

道場Tierで上位の候補：トコペン系（SS）、フクロクモ系（S）。属性・配置などを含む実戦判断はバッジ道場攻略を優先します。

ボスラリー

現行Tier DBにはBoss Rally専用の評価列がないため、このページでは順位を作りません。ボス別の確認済み対策と手持ち条件はボスラリー攻略で確認してください。

初心者・育成優先の考え方

初心者向けの見方

初心者は初心者評価と通常評価を見て、手持ちの前衛・回復役との重複を避けながら不足役割を補ってください。

  1. 初心者Tierと通常Tierを見て、今使うモードに合う候補を絞る。
  2. 個別ページで現在の進化段階と確認済みスキルを比べる。
  3. 同じ役割の重複より、不足している火力・妨害・生存補助を優先する。
  4. 進化優先度で必要星数と進化差分を確認してから素材を使う。

関連する役割と確認先

タンク役を見る回復役を見るバフ役を見る役割一覧へ戻るデータ更新・検証方針
確認済み情報と独自評価の区別

系統名・役割ラベル・各用途Tier・個別ページのスキル値は既存DBから表示しています。場面別の読み方と育成手順は当サイトの独自整理です。ゲーム内で確認できない仕様やBoss専用順位は作成していません。
