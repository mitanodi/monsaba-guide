# 攻略DB UX benchmark — 2026-09-06

競合のゲーム情報・画像・評価・固有デザインは転用しない。実際に開けたページの情報構造と操作だけを比較した。網羅的な競合機能調査ではない。

| サイト / 実ページ | 確認した操作・構造 | モンサバでの判断 |
|---|---|---|
| [Game8](https://game8.jp/) | ホームのゲーム検索導線を押し検索欄とゲーム一覧を表示 | 名前検索を主要導線として維持。現在のTOP検索とグローバル検索を実操作で再確認 |
| [GameWith](https://gamewith.jp/walkthrough) | TOPの「攻略」から攻略一覧へ移動。総合ニュースと攻略検索が別の入口になっている | タタ・攻略・育成・ツール・コミュニティの既存目的別グループを維持。ニュース中心への全面置換は不要 |
| [Prydwen HSR](https://www.prydwen.gg/star-rail) | Database / Tier / Endgame / Tools / Guidesの区分とショートカット | TOPの編成ツール説明が実際の5mode対応と一致するよう修正 |
| [Prydwen Tier](https://www.prydwen.gg/star-rail/tier-list) | 更新日・対象mode・前提説明・Criteriaの開閉。Fireフィルターを押すとResetが有効 | モンサバのTier根拠とmode別評価・保留枠を残す。順位だけを大きくする変更や他ゲームの評価転載はしない |

共通原則は「目的で入口を分ける」「現在の条件を明示する」「長い根拠を必要に応じて開く」「選択状態から戻れる」。今回の優先事項は装飾追加ではなく、モード往復での編成保全とクリック/ドラッグの信頼性。非ZRをZR投稿へ変換しないガードと、未保存時の次の行動の明示にも適用した。

Mobalytics、Maxroll、Genshin Optimizer等は今回の実操作比較対象外。閲覧していない挙動を推測して評価しない。各社の配置や広告量をそのまま模倣せず、現在のモンサバの低密度広告・非公式表記・公式素材の出典区分を保つ。
