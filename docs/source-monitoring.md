# 外部ソース監視方針

監視対象は `data/external-source-watch.json` で管理します。公式更新履歴を一次情報、国内外攻略サイトを二次情報として扱い、確認日・対象バージョン・信頼区分を保持します。

- 外部本文・画像・表・コードを収集して再公開するcrawlerは作りません。
- 更新差分は名称、仕様、数値、条件、更新日、Tier傾向だけを照合し、文章は当サイト独自に作成します。
- 二次情報だけの項目は「外部確認」、古いバージョンは「旧仕様」、根拠不足は「確認待ち」と表示します。
- Tierは単一サイトを転記せず、公式バランス変更・対象バージョン・複数ソース・自サイトの既存理由を差分監査します。
