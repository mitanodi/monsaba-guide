## 照合方法

英語PDFと中国語PDFの同じページ番号を対応させる方法は使用していない。各PDFを独立に全ページ画像化し、既存 `data/tatari.json` の64系統・230形態を正規IDとして照合した。

照合には次を併用した。

1. タタ本体の画像特徴点
2. 進化アイコン列
3. 同一系列内の進化関係
4. 進化段階と系列内の一対一対応
5. シルエット時の前後アイコンと系列構成
6. タイトル文字のOCR
7. 全タイトル画像の目視確認

英語名は全件をタイトル画像と照合した。簡体字中国語名はOCRで起きた `兔 / 免`、`鸮` の欠落、類似字などの誤読をタイトル画像の目視確認で修正した。翻訳から名称を推測した項目はない。

ユーザー提示の確認例も一致した。

- Punchimp / Rockfu / Rockwu / Rockong = 顽皮吗喽 / 棍棒吗喽 / 天命吗喽 / 大圣吗喽
- Dewgrub / Ripplewing / Waveflutter = 露水虫 / 露水蝶 / 水舞蝶
- Rubblet / Cobbledon / Rockzilla / Meteorax = 小岩蜥 / 烈岩蜥 / 岩暴龙 / 陨岩龙

## 曖昧候補と解決

初回の単一画像スコアでは、未解放シルエットや同系列の近い絵柄により、ネムクラゲ系とマドブヒ系などで進化段階の順位が近い箇所があった。これらはページ番号の言語間対応ではなく、同一PDF内の系列まとまり、進化アイコン列、既存系列の段階数、形態画像の一対一割当、タイトル目視を組み合わせて解決した。

解決後に複数候補が残る形態、片言語だけの形態、既存日本語データにない形態はないため、最終 `needs-review` は0件とした。
