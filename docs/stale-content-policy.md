# Stale content policy

日付を伴う「実装予定」「開始予定」「明日実装」「実装後に確認」「実装後更新」「メンテナンス予定」は、基準日を過ぎたまま公開しません。

- 実装を公式情報で確認できた場合は「実装済み」に更新する。
- 実装は確認できてもゲーム内の数値などが未確認なら「実装済み・詳細確認中」と分ける。
- 第三者情報だけで正式値を補完しない。
- 過去予測は「予測履歴」と明記し、予測値自体を書き換えない。
- 例外は `data/stale-content-exceptions.json` にファイル単位・理由付きで登録する。
- CIでは `npm run validate:stale` を実行する。再現時は `CONTENT_CURRENT_DATE=YYYY-MM-DD` を指定できる。

日付だけの機械置換は行わず、事実の状態を更新してから文言を変更します。
