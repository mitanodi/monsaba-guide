# オタカラ探しソルバー設計

外部サイトのソース、HTML、CSS、UIは使用せず、ゼロから実装しています。

1. 指定された幅・高さの宝について、盤面内に収まる全配置を列挙する。
2. 「空白」を含む配置を除外する。
3. 宝どうしが重ならない組み合わせを深さ優先探索する。
4. 「宝ヒット」「発見済み」がすべて含まれる組み合わせだけを有効候補にする。
5. 各未確認セルを含む候補数 ÷ 全候補数で存在確率を計算する。
6. 最大確率セルをおすすめとして表示する。

組合せ爆発を避けるため有効候補は20,000件で打ち切り、その場合は概算と表示します。入力とUndo履歴は個人情報を含まず、現在盤面だけをlocalStorageへ保存します。Analyticsにはツール名と操作種別だけを送り、盤面内容は送りません。
