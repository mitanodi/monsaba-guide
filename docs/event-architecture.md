# イベント攻略アーキテクチャ

`data/events.json` でイベント名、状態、URL、確認状態を管理し、`/events/` を入口にします。

- `periodic`: 周期イベント。開催期間を確認できない場合は「開催中」と断定しない。
- `scheduled`: 公式日時が将来の場合だけ使用する。
- `ended`: 公式終了日時を確認できた場合に使用する。
- `permanent`: 常設であることを確認できた場合に使用する。

各イベントのゲーム内値と独自ツールの計算結果を分離します。オタカラ探しソルバーはゲーム内正式値を保持せず、ユーザー入力だけを端末内で計算します。
