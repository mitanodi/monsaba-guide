ガオデン系は育てる価値ある？

ガオデン → ガルルデン → キングデン → エンペラデン

  • 範囲攻撃
  • ノックバック
  • 第3進化から被ダメージ増加20%
  • 第4進化で雷オーラ

弱くはない。ノックバックによる押し返しと、第3進化以降の被ダメージ増加が強み。ただし現状の総合・ゾンビラッシュ評価では、プラビ・デンジカ・ビリモリなどを先に育てる価値が高い。

ガオデン系を見る

プラビ vs デンジカ

プラビ系

  • 回復
  • バフ
  • 生存

デンジカ系

  • 火力
  • 貫通
  • 麻痺
  • CC

回復・安定性不足ならプラビ。敵処理・足止め不足ならデンジカ。ゾンビラッシュでは両方とも最上位候補なので、最終的には両方育てる価値があります。

進化で大きく化ける雷タタ

プラビ第2進化でピンチ時無敵、第3進化で高速回復を追加。
デンジカ第3進化で4回攻撃ごとに無限貫通が追加。
ビリピヨ第3進化で強化充電・攻撃力増加50%が追加。
ガオデン第3進化で被ダメージ増加20%が追加。
デンロウ第3進化で攻撃中の無敵が追加。
