進化すると何が変わる？

T1 ポタカゲ → T2 ピチャカゲ

  • スキル名：泡 → 渦

T2 ピチャカゲ → T3 アクアガマ

  • スキル名：渦 → 激流
  • 「ステルス」時クールダウン：2.5秒（追加）

T3 アクアガマ → T4 イガマスター

  • スキル名：激流 → 渦潮
  • オーラ・水 回復倍率初期値：対象のHPの0.5%（追加）
  • オーラ・水 最大回復倍率：対象のHPの2.5%（追加）
  • オーラ・水 回復間隔：4秒（追加）
