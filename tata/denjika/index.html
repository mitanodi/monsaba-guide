ビリジカは強い？

貫通・麻痺・束縛による火力とCCを両立。海外のOverall・Boss・Dojo評価と国内評価が重なり、複数モードで長く使える。

主な役割

貫通麻痺CC

評価保留は弱いという意味ではなく、順位を付ける根拠が不足している状態です。

ビリジカは進化するべき？

  • T2→T3 優先候補：攻撃4回ごとの無限貫通が追加される。貫通性能が大きく伸び、敵が密集する場面で強化される。

ビリジカの進化先

T1ビリジカ
T2デンジカ
T3ジバジカ
T4マグネクス

進化すると何が変わる？

T1 ビリジカ → T2 デンジカ

  • スキル名：ビリリランス → ボルトランス
  • 貫通回数：2 → 3

T2 デンジカ → T3 ジバジカ

  • スキル名：ボルトランス → エレキランス
  • 無限貫通の頻度：攻撃4回ごと（追加）

T3 ジバジカ → T4 マグネクス

  • スキル名：エレキランス → 超科学エレキランス
  • オーラ・雷 攻撃速度増加初期値：4%（追加）
  • オーラ・雷 攻撃速度増加最大値：20%（追加）
