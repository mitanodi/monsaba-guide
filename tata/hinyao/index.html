範囲攻撃で複数レーンに火力を出しやすい。ニャンコ系との組み合わせも狙える。

ヒニャオは進化するべき？

現在評価情報を収集中です。根拠のない進化推奨は掲載していません。

ヒニャオの進化先

進化 1ヒニャオ
進化 2マネヒネコ
進化 3ネコマダラ

進化すると何が変わる？

T1 ヒニャオ → T2 マネヒネコ

  • スキル名：バチバチニャン弾 → アツアツニャン弾
  • バウンス回数増加頻度：攻撃5回ごと → 攻撃4回ごと
  • バウンス回数最大値：2 → 3
  • ニャンコの絆 最大拡大回数：2 → 3

T2 マネヒネコ → T3 ネコマダラ

  • スキル名：アツアツニャン弾 → メラメラニャン弾
  • ヒニャオ 攻撃力増加比率：15%（追加）
