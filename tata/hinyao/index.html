進化すると何が変わる？

T1 ヒニャオ → T2 マネヒネコ

  • スキル名：バチバチニャン弾 → アツアツニャン弾
  • バウンス回数増加頻度：攻撃5回ごと → 攻撃4回ごと
  • バウンス回数最大値：2 → 3
  • ニャンコの絆 最大拡大回数：2 → 3

T2 マネヒネコ → T3 ネコマダラ

  • スキル名：アツアツニャン弾 → メラメラニャン弾
  • ヒニャオ 攻撃力増加比率：15%（追加）
