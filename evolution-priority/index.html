進化優先度ランキング・第3進化おすすめ

序盤は第3進化に必要な星数が少ないタタを優先すると効率が良い。ただし、長期的な育成価値やコンテンツによって優先順位は変わります。

進化診断へ

運営・データ確認：おぢ

進化は「タタの強さ」と「その段階に素材を使う価値」を分けて判断

最短T3はネコオリ / ヒモリ / フルッグ。次点はガオデン / ガントル（初期：コロカメ） / ヒマワリン。長期育成ではフレイムシ（初期：ヒノムシ） / ヒマワリン / ヤンザル / プラビが候補です。

第4進化（T4）はどこまで優先する？

T4オーラの見方

多くの4段階系統では、T4で属性オーラが追加されます。オーラの数値は各タタのT4スキルデータから表示します。

  • オーラ・炎：仲間の攻撃力増加
    例：オーラ・炎 攻撃力増加初期値 2.5% / オーラ・炎 攻撃力増加最大値 12.5%
  • オーラ・雷：仲間の攻撃速度増加
    例：オーラ・雷 攻撃速度増加初期値 4% / オーラ・雷 攻撃速度増加最大値 20%
  • オーラ・草：仲間のHP増加
    例：オーラ・草 HP増加初期値 4% / オーラ・草 HP増加最大値 20%
  • オーラ・水：仲間を継続回復
    例：オーラ・水 回復倍率初期値 対象のHPの0.5% / オーラ・水 最大回復倍率 対象のHPの2.5% / オーラ・水 回復間隔 4秒
  • オーラ・岩：仲間の被ダメージ減少
    例：オーラ・岩 被ダメージ減少UP初期値 3.5% / オーラ・岩 被ダメージ減少UP最大値 17.5%
ゾンビラッシュでは第4進化のオーラは無効

ゾンビラッシュ目的なら、オーラだけを理由にT4を最優先する必要はありません。ただし基礎ステータス変化や他コンテンツでの利用はあり得るため、T4にする意味がないとは扱いません。
